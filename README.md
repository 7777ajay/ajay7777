# Ajay Merapureddy Portfolio

Professional Angular portfolio for Ajay Merapureddy, built from `Ajay_Resume.pdf` and supplied photo assets only.

## Stack

- Angular 21
- SCSS
- Motion / Framer-style reveal animation
- Lucide Angular icons
- Vercel deployment config

## Routes

- `/about-me` - main portfolio page
- `/` - redirects to `/about-me`

## Local Development

```bash
npm install
npm start
```

## Build

```bash
npm run build
```

## Test

```bash
npm test -- --watch=false
```
